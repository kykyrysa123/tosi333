Задание в методичке:
1. Ознакомиться с теоретической частью.
2. Для тестовых музыкальных файлов, выданных преподавателем, необходимо выполнить следующие задания:
– реализовать алгоритм вычисления спектрограммы или мел-спектрограммы (по варианту);
– реализовать алгоритмы вычисления спектрограммы и мел-спектрограммы с использованием готовых библиотек;
– объяснить полученный результат.
3. Вычислить спектральные признаки аудиосигнала:
– реализовать алгоритмы вычисления спектрального центроида, спектрального спада,
спектральной ширины, частоты пересечения нуля, мел-частотных кепстральных коэффициентов
и цветности с использованием готовых библиотек (для более качественного освоения материала
рекомендуется выбрать несколько признаков и реализовать их самостоятельно);
– объяснить полученный результат.
4. Написать функцию, которая будет смешивать чистый голос и шум по заданному в децибелах SNR
(диапазон значений SNR и шаг определяет преподаватель).
5. Сравнить методы оценки качества звука (метрики, которые необходимо
реализовать самостоятельно, определяет преподаватель, для остальных метрик
допускается использование библиотечных реализаций).
Объективная оценка:
SNR SDR SI-SDR PESQ NISQA DNSMOS
И субъективная
Прим. 1. Рекомендуется опросить нескольких человек для субъективной оценки тестовых файлов.
Прим. 2. Сделать выводы о корреляции значений аналитических и перцептивных метрик.
6. Скачать с официального репозитория проект DeepFilterNet2
(по согласованию с преподавателем допускается использовать более актуальные проекты).
Обработать с его помощью зашумленные файлы. Повторить тесты из п.5.

Пояснение к заданию (имеет больший приоритет, чем задание из методички):
Для пунктов 2, 3 в качестве тестовых фалов выбрать 4 музыкальных файла различных жанров
Для пунктов 4, 5, 6 в качестве тестовых фалов записать свой голос
Тип представления: Мел‑спектрограмма
Признаки (2, которые нужно реализовать самостоятельно): MFCC, спектральная ширина
С помощью библиотечных функций вычислить ещё 3 любых признака и MFCC со спектральной шириной для сравнения с самостоятельной реализацией
Метрики, которые нужно реализовать самим: SNR, SDR
С помощью библиотечных функций вычислить ещё 3 любые метрики и SNR с SDR для сравнения с самостоятельной реализацией
Модель шумоподавления: mossformer2 (я согласовал с преподавателем эту модель, использовать вместо DeepFilterNet2)
Диапазон SNR (дБ): 3–18
Шаг SNR (дБ): 3
